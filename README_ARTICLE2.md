## Описание

Эта статья является логическим продолжением первой работы о теоретической постановке задачи термоупругости. Здесь представлен численный метод решения полученных уравнений.

## Основное содержание

### Тема
Разработка конечно-разностного метода для решения связанной задачи термоупругости в цилиндрических координатах.

### Ключевые результаты

1. **Конечно-разностная схема** - явная схема для уравнений теплопроводности и движения в координатах (r, φ, z)
2. **Условие устойчивости** - обобщённый критерий CFL для цилиндрической геометрии
3. **Алгоритм связанного решения** - эффективный итерационный метод
4. **Верификация** - погрешность не превышает 0.6% на тестовых задачах

### Структура (IMRAD)

- **Введение** - актуальность численных методов для цилиндрических тел
- **Методология** - дифференциальная постановка, дискретизация, условия устойчивости
- **Результаты** - алгоритм, оценка погрешности, верификация на полом цилиндре
- **Обсуждение** - сравнение с МКЭ, вычислительная эффективность, ограничения
- **Заключение** - 4 основных результата и направления развития

### Математические уравнения

Статья содержит 8 уравнений:

1. **Уравнение теплопроводности** в цилиндрических координатах
2. **Уравнение движения** (радиальное направление)
3. **Конечно-разностная схема** (явная)
4. **Условие устойчивости CFL** для 3D случая
5. **Связь напряжений и деформаций** (дискретная)
6. **Вычисление деформаций** из перемещений
7. **Связанная система** тепловой и механической задач
8. **Оценка погрешности** в норме L²
